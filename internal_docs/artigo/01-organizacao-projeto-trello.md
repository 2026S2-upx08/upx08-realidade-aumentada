# Organização do Projeto e Gestão da Equipe (Trello)

## Objetivo

Estruturar a organização inicial do projeto (papéis, planejamento,
ferramenta de gestão) e manter um acompanhamento contínuo e **atualizado**
ao longo de toda a disciplina — não é uma entrega única, é um artefato vivo.

## Ferramenta

Trello, seguindo o modelo apresentado em aula.

## Estrutura obrigatória do quadro (listas)

- [ ] Informações do Projeto
- [ ] Backlog
- [ ] Andamento
- [ ] Espera
- [ ] Concluído

## Preenchimento obrigatório por lista

### Informações do Projeto (cartões obrigatórios)

- [ ] Equipe (nome, RA, contato e função de cada integrante)
- [ ] Repositórios e links importantes
- [ ] Pesquisas e fundamentação
- [ ] Objetivo do projeto
- [ ] Como utilizar o quadro

### Backlog

- [ ] Atividades planejadas do projeto
- Cada cartão deve ter:
  - [ ] título da atividade
  - [ ] descrição
  - [ ] checklist (quando necessário)

### Andamento

- Cada cartão deve ter:
  - [ ] responsável
  - [ ] etiquetas
  - [ ] data de entrega
  - [ ] descrição da atividade

### Espera

- [ ] Atividades dependentes de fatores externos
- [ ] Justificativa clara para cada uma

### Concluído

- [ ] Atividades finalizadas
- [ ] Evidência da execução em cada cartão

## Requisitos gerais do quadro

- [ ] Segue o modelo apresentado em aula
- [ ] Identificado com Nome da Equipe / Nome do Projeto
- [ ] Todos os integrantes adicionados ao quadro **+ o professor**
- [ ] Atividades distribuídas entre os membros (não concentradas em 1 pessoa)
- [ ] Estrutura organizada e clara
- [ ] Atualização contínua (isso será avaliado ao longo do tempo, não só na entrega)

## Atas de reunião

- [ ] Toda reunião de mentoria deve ter ata registrada
- [ ] As atas devem ser entregues nesta atividade

## Critério de avaliação "Evolução do Projeto" (obrigatório)

Não basta preencher o quadro uma vez — será avaliado:

- [ ] Evolução das atividades ao longo do tempo
- [ ] Movimentação real dos cartões entre as listas
- [ ] Registro das ações realizadas pela equipe
- [ ] Coerência entre planejamento e execução
- [ ] O quadro reflete o estado real do projeto

## Entrega

- [ ] Link de acesso ao quadro (com permissão de visualização)

## Critérios de avaliação (resumo)

1. Organização do quadro conforme modelo
2. Qualidade do preenchimento das listas e cartões
3. Distribuição de tarefas entre os integrantes
4. Evolução e atualização do projeto
5. Coerência entre planejamento e execução

## Observações importantes

- Quadro incompleto/desorganizado/sem atualização impacta diretamente a nota.
- Falta de movimentação = interpretada como falta de desenvolvimento do projeto.
- O quadro é o registro oficial da evolução do projeto.
