# Artigo Científico — Versão 1 do Projeto Experimental

## Objetivo

Iniciar formalmente o artigo científico do projeto, com base apenas no que
já foi trabalhado nas 4 primeiras aulas. Esta é a **Versão 1**, a ser
aprimorada ao longo do semestre (artefato, experimento, dados, resultados,
discussão virão depois).

## Modelo obrigatório

- Usar o arquivo de modelo: `FSGQ-19.02.01 rev. 03 - MODELO DE ARTIGO CIENTÍFICO.docx`
- Apoio: PDF "AULA EXTRA — USO DO MODELO DE ARTIGO"
- [ ] Estrutura e formatação do modelo preservadas

- [ ] Feito em equipe (mesma equipe do projeto experimental)
- [ ] **Cada integrante** localizou, selecionou, analisou e adicionou

- [ ] Coerência entre a planilha de artigos e o texto do artigo (artigos da
      planilha realmente citados/usados no corpo do texto)

## Documento 1 — Artigo científico (Versão 1)

### Elementos do modelo a preencher

- [ ] **Título** (PT) — específico: tecnologia/abordagem + contexto + problema/finalidade
      (evitar títulos genéricos tipo "Realidade Aumentada na Educação")
- [ ] **Título em inglês**
- [ ] **Autores** — todos que participaram efetivamente, ordem definida pela equipe
- [ ] **Resumo** (até 250 palavras), contendo:
  - [ ] contexto
  - [ ] problema investigado
  - [ ] motivação
  - [ ] objetivo do trabalho
  - [ ] abordagem metodológica planejada
  - [ ] artefato/solução a ser investigado
  - [ ] **sem resultados inventados** (pesquisa ainda não executada)
- [ ] **Palavras-chave** (3–5), coerentes com termos de busca da Aula 2
- [ ] **Abstract** (versão em inglês do resumo)
- [ ] **Keywords** (versão em inglês das palavras-chave)

### Introdução (parte mais importante desta entrega)

Não pode ser lista de definições genéricas sobre RA — precisa conduzir o
leitor até a questão de pesquisa. Progressão sugerida:

- [ ] Contextualização (inclui relação com ODS, se houver — explicando a
      relação, não só citando o número do ODS)
- [ ] Importância do tema
- [ ] Problema existente (não começar pela tecnologia; é uma situação a
      investigar, não "desenvolver uma aplicação em RA")
- [ ] O que a literatura já investigou (Estado da Arte)
  - [ ] Compara e relaciona trabalhos (não apenas "Segundo Autor A...")
  - [ ] Identifica tecnologias usadas, como foram avaliadas, resultados, limitações
- [ ] Limitação/lacuna identificada na literatura
- [ ] Motivação (relevância social / educacional / econômica / tecnológica /
      científica / ambiental / ODS)
- [ ] Problema de pesquisa
- [ ] Questão de pesquisa (RQ) — clara, específica, investigável,
      respondível com dados, compatível com o projeto do semestre
- [ ] Hipótese (H1...) — proposição confrontável com evidências futuras
      (não "a aplicação será melhor")
- [ ] Objetivo geral — verbo tipo investigar/avaliar/analisar/comparar/
      desenvolver e avaliar
- [ ] Objetivos específicos — decompõem o objetivo geral em etapas
      (algumas ainda não executadas, mas podem aparecer como objetivos)

### Fundamentação Teórica / Trabalhos Relacionados (seção 2)

- [ ] Usa efetivamente os artigos da planilha
- [ ] Não é resumo individual de cada artigo — é discussão comparativa
- [ ] Responde: o que já existe? como o problema vem sendo tratado? quais
      soluções? como avaliadas? quais limitações permanecem? onde nossa
      pesquisa se posiciona?

### Metodologia — versão inicial (só até o conteúdo da Aula 4)

- [ ] **Natureza**: básica ou aplicada — classificada e justificada
      (a maioria dos projetos = aplicada)
- [ ] **Objetivos**: exploratório / descritivo / explicativo / combinação —
      classificado e justificado, coerente com a RQ e objetivo geral
- [ ] **Abordagem**: quantitativa / qualitativa / mista — indicada e justificada
- [ ] Tipos de dados que pretende coletar (ex.: quantitativos — tempo, erros,
      taxa de sucesso, SUS; qualitativos — observações, entrevistas)

### O que NÃO escrever ainda (proibido nesta versão)

- [ ] Nenhum procedimento experimental completo
- [ ] Nenhuma arquitetura definitiva
- [ ] Nenhuma implementação
- [ ] Nenhum teste técnico ou com usuários
- [ ] Nenhum resultado
- [ ] Nenhuma discussão de resultados
- [ ] Nenhuma conclusão definitiva
- [ ] Nenhum resultado/experimento inventado — usar verbos como "será
      desenvolvido", "pretende-se avaliar", "serão coletados", "propõe-se investigar"

Citações no artigo → Referências
