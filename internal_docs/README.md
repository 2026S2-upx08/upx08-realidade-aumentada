## `pitch_e_slides/` — as duas entregas da AF, prazo 08/11/2026

Duas atividades diferentes, não confundir uma com a outra:

- `atividade_e_creterios_entrega_pitch.txt` — enunciado do **vídeo pitch** (3 a 4 min, com demonstração do protótipo, webcam ligada, link do YouTube não listado). Roteiro obrigatório: identificação do projeto, descrição, problema/público-alvo, proposta de solução, demonstração da prototipação (parte principal), estrutura técnica, planejamento, conclusão.
- `atividade_e_creterios_entrega_slides.txt` — enunciado dos **slides pra Mostra de Projetos 2026** (apresentação presencial, 5 a 8 min), usando obrigatoriamente o template institucional do Canva (link no próprio arquivo). Entrega é só o link do Canva (não aceita pptx/pdf como entrega), mas vale levar um PDF no pen drive como backup pro dia.
- `template_mostra_de_projetos_ unifacens_2026.pptx` / `.pdf` — cópia exportada do template oficial do Canva, só pra consulta offline (a entrega real tem que ser feita no Canva mesmo, pelo link). Estrutura do template: Título → Contextualização/Problema → Objetivos → Metodologia → Desenvolvimento → Resultados → Conclusões → Referências e Contatos → QR Code (bate exatamente com as 9 seções pedidas no enunciado dos slides). Depois do QR Code vêm vários slides de layout genérico (lista de itens, métricas, citações) — são templates extras opcionais, não fazem parte da estrutura obrigatória.
